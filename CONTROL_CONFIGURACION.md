# Control de Configuración del Sistema MCRT

El proyecto MCRT utiliza Git/GitHub para controlar la evolución del software.

## Ramas utilizadas

- main: contiene versiones funcionales del sistema.
- lider: rama de integración y desarrollo principal.
- renzo: evolución de la pantalla Registrar Factura.
- daniel: evolución de la pantalla Registrar Recibo por Honorarios.
- fernando: evolución de la pantalla Ver Historial.

## Ítems de configuración

- Código fuente C#.
- Formularios Windows Forms.
- Clases de modelo.
- Servicios de cálculo tributario.
- Interfaces de cálculo.
- Repositorios.
- Documentación.
- Evidencias de commits y ramas.
