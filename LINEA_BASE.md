# Línea Base del Proyecto MCRT

## Línea Base 1.0

La línea base inicial corresponde al sistema funcional presentado en la T2.

Incluye:

- Menú principal.
- Registro de facturas.
- Registro de recibos por honorarios.
- Historial de comprobantes.
- Cálculo de IGV.
- Cálculo de retención de cuarta categoría.

## Línea Base 2.0

Corresponde a la versión evolucionada para la evaluación final.

Incluye:

- Validaciones mejoradas.
- Mejoras en pantallas principales.
- Trazabilidad en historial.
- Control de versiones mediante ramas Git.
