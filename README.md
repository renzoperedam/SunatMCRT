# Sistema Tributario MCRT

El Sistema Tributario MCRT es una aplicación desarrollada en C# para registrar comprobantes tributarios, calcular IGV, calcular retenciones de cuarta categoría y visualizar el historial de operaciones.

## Ramas del proyecto

- main: versiones funcionales.
- lider: integración del desarrollo.
- renzo: mejoras en factura.
- daniel: mejoras en recibo por honorarios.
- fernando: mejoras en historial.
